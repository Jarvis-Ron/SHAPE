# NYC-to-CA reference evidence

The recorded metric draws, their summaries, and a previous native generation
regression are retained as numerical evidence. Anonymous paths replace local
machine paths. The actual data, weights and predictions are now bundled under
`inputs/nyc_to_ca/`; all four current result records are in `reference_results/`.
Use the root `run_full_pipeline.py` for the four-direction release. Historic
schema and candidate labels identify artifact formats, not extra model choices.
